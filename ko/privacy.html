개인정보 처리방침

최종 업데이트: 2026년 9월 20일.

FerryPorts는 郭耀铭(Guo Yaoming)이 개발했으며, 사용자가 선택한 frps 서버에 연결합니다. 이 방침은 앱과 이 지원 웹사이트에 적용됩니다.

  • 광고나 사용 추적이 없습니다

    FerryPorts 계정은 필요하지 않습니다. 앱에는 광고, 광고 추적, 사용 분석 서비스가 없습니다.

  • 설정과 기록은 기기에 보관됩니다

    서버 설정과 연결 기록은 로컬에서 암호화됩니다. 앱은 진단 로그, 위치, 연결 기록을 개발자에게 자동으로 업로드하지 않습니다. 다만 연결 프로토콜과 사용자가 활성화한 기능에 따라 아래에 설명된 설정 및 기타 데이터가 전송될 수 있습니다.

  • 위치 사용은 선택 사항입니다

    권한이 허용되면 앱은 활성 연결에 대략적인 위치를 표시합니다. 각 연결에는 최신 위치만 보관하며 이동 경로는 저장하지 않습니다. iOS 설정에서 위치 접근을 끌 수 있습니다.

  • 연결에는 네트워크 접근이 필요합니다

    선택한 서버는 연결 설정, 인증, 프록시 통신에 필요한 데이터를 받습니다. Apple 지도와 웹사이트 호스팅 제공자인 GitHub도 서비스 제공에 필요한 요청 정보를 처리합니다.

  • 로컬 데이터를 삭제할 수 있습니다

    연결 기록이나 프로필을 삭제할 수 있습니다. 설정과 키를 제거하려면 앱 내에서 프로필을 삭제하세요. 앱을 제거하는 것만으로는 키체인 항목이 남을 수 있습니다. 로컬 데이터를 삭제해도 서버 로그는 삭제되지 않습니다.

데이터 처리 방식

각 제목을 펼치면 저장 방식, 제3자 서비스, 삭제의 한계를 자세히 확인할 수 있습니다.

기기에 저장되는 데이터

서버 설정, 인증 정보, 프록시 설정은 AES-GCM으로 암호화된 문서에 저장됩니다. 문서 키는 기기에 귀속된 시스템 키체인 항목에 저장됩니다. 프로필 이름, 활성화 상태, 문서 식별자는 앱의 로컬 환경설정에 저장되며, 앱은 인증 암호를 프로필 이름에 넣지 않습니다. 암호화된 설정 파일과 연결 기록 파일은 시스템 백업에서 제외됩니다.

현재 세션의 진단 로그는 앱에 표시하기 위해 크기가 제한된 메모리 버퍼에 보관됩니다. 서버 주소, 프록시 이름, 타임스탬프, 오류가 포함될 수 있습니다. 앱은 이러한 로그를 개발자에게 자동으로 업로드하지 않습니다. 로그 내용을 복사하거나 공유하면 수신자는 사용자가 제공한 내용을 받게 됩니다.

위치 및 연결 기록

권한이 허용되면 연결을 시작하거나 실행하는 동안 대략적인 위치를 연결 기록에 표시합니다. 각 세션은 최신 위치만 보관하며 이동 경로, 고도, 속도, 방향은 저장하지 않습니다. 각 프로필은 시작 시간, 최근 활동 시간, 결과를 포함하는 최신 기록을 최대 50개 보관합니다.

이 기록은 로컬에서 암호화됩니다. 앱 자체는 위치나 연결 기록을 개발자 또는 frps 서버에 업로드하지 않습니다. 지도에는 Apple MapKit을 사용합니다. Apple 지도 서비스에 필요한 요청과 처리에는 Apple 개인정보 처리방침이 적용됩니다. 지도가 완전히 오프라인으로 작동한다고 보장하지 않습니다.

iOS 설정에서 위치 접근 권한을 변경하거나 철회할 수 있습니다. 백그라운드 위치는 활성 연결 기록에 위치를 표시하며, 백그라운드에서 연결을 더 오래 유지할 수 있도록 도울 수도 있습니다. 권한 변경, 앱 강제 종료, 시스템에 의한 종료로 이 동작이 중단될 수 있습니다.

사용자가 선택한 서버

프로필을 활성화하면 연결 설정, 인증, 프록시 협상에 필요한 데이터가 선택한 frps 서버로 전송됩니다. frp 로그인 프로토콜에는 운영체제가 반환하는 호스트 이름, 운영체제 유형, 프로세서 아키텍처, frp 버전, 로그인 타임스탬프, 세션 식별자, 설정된 사용자 이름, 클라이언트 식별자, 메타데이터가 포함됩니다. iOS가 반환하는 호스트 이름은 일반적인 이름일 수 있습니다. 이는 연결 프로토콜의 필드이며 FerryPorts 광고 식별자가 아닙니다. 서버는 설정된 서비스 제공에 필요한 인증 프로토콜 데이터와 프록시 설정도 받습니다.

서버와 통신 엔드포인트는 IP 주소, 연결 시간, 설정된 프록시 통신을 받을 수 있습니다. 활성화한 기능에 따라 DNS 제공자는 도메인 조회를 받고, OIDC 인증 제공자는 설정된 클라이언트 인증 정보와 토큰 요청 매개변수를 받으며, XTCP NAT 통과 기능은 네트워크 주소를 확인하기 위해 STUN 서비스에 접속합니다. 다른 STUN 서버를 설정하지 않으면 frp는 기본적으로 stun.easyvoip.com:3478을 사용합니다. 일반적인 프록시 연결에는 이 XTCP 탐색 단계가 필요하지 않습니다. 프록시, 인증 및 기타 엔드포인트도 설정에서 선택할 수 있습니다.

가져온 인증서와 개인 키는 앱 컨테이너 안에 평문 PEM으로 저장되며, 최초 잠금 해제 후 사용할 수 있는 iOS 데이터 보호로 보호됩니다. iCloud 및 Finder 백업에서는 제외됩니다. 프로필 문서에 적용되는 앱 수준의 암호화는 사용하지 않습니다. 더 보기 → 인증서 및 키에서 이 파일을 삭제하세요. 프로필을 삭제해도 다른 프로필에서 함께 사용할 수 있는 인증서는 자동으로 삭제되지 않습니다. 외부 원본과 복사본은 사용자가 관리해야 합니다.

설정된 인증서 파일, token 파일, 정적 파일 제공 디렉터리는 앱 컨테이너 내부로 제한됩니다. 이 경계를 벗어나는 경로와 심볼릭 링크는 거부됩니다. 사용자 지정 DNS 질의는 선택한 DNS 서비스에서 처리합니다.

static_file 플러그인을 활성화하면 해당 서비스에 대한 요청으로 설정된 디렉터리에서 읽을 수 있는 파일을 가져올 수 있으며, 여기에는 디렉터리 목록과 크기, 수정 시간 등의 파일 메타데이터가 포함됩니다. HTTP 응답에는 Last-Modified 헤더가 포함될 수 있습니다. 이는 사용자가 설정한 파일 제공 기능이며 진단 분석이 아닙니다. frp 관리 웹 서버를 활성화하면 접근 가능한 클라이언트가 사용자가 선택한 인증 및 네트워크 설정에 따라 연결 상태와 설정 정보를 얻을 수 있습니다.

수신자, 암호화, 로그 보관 기간, 처리 방식은 서버, 서비스, 설정에 따라 달라집니다. 신뢰할 수 있고 사용 권한이 있는 서버에만 연결하고 운영자의 개인정보 처리방침을 확인하세요. 로컬 저장이 네트워크 전송이 없다는 뜻은 아닙니다. 네트워크 통신은 앱 기능의 핵심입니다.

데이터를 삭제한 뒤 무엇이 남나요?

개별 연결 기록을 삭제하거나 전체 기록을 지울 수 있습니다. 프로필을 삭제하면 해당 프로필의 암호화된 설정 문서, 연결 기록, 문서 키가 제거됩니다. 앱을 제거하면 일반적으로 앱의 로컬 데이터 컨테이너가 삭제되지만 iOS 키체인 항목은 남을 수 있습니다. 키를 제거하려면 먼저 앱 안에서 프로필을 삭제하세요. 로컬 삭제는 서버 로그, 다른 곳에 저장한 복사본, 다른 플랫폼에 게시한 콘텐츠를 지우지 않습니다.

이 웹사이트를 방문하거나 문의할 때 어떤 정보가 사용되나요?

이 웹사이트는 GitHub Pages에서 호스팅되며 별도의 분석 스크립트, 광고, 추적 쿠키를 추가하지 않습니다. GitHub는 GitHub 개인정보처리방침에 따라 호스팅을 제공하고 보호하기 위해 IP 주소와 기술적 요청 정보를 처리할 수 있습니다. GitHub를 통해 문의하면 GitHub와 관리자가 사용자가 제공한 내용을 처리합니다. 공개 이슈는 누구나 볼 수 있습니다. eric_kwoc@icloud.com으로 이메일을 보낼 수도 있습니다. 작성자가 피드백을 받아 처리하며 공개하지 않습니다. 관련 이메일 제공자는 이메일 전달과 저장을 처리합니다. 인증 정보, 전체 설정, 개인 위치가 담긴 스크린샷은 게시하지 마세요.
