frp 소개

frp란 무엇인가요?

frp는 오픈 소스 리버스 프록시 도구입니다. 인터넷에서 접속할 수 있는 서버를 통해 NAT나 방화벽 뒤에 있는 로컬 서비스에 접근할 수 있게 해 줍니다.

집이나 사무실 네트워크의 서비스는 인터넷에서 직접 접근하지 못할 수 있습니다. frp는 해당 서비스를 직접 관리하는 서버에 연결해 서버가 요청을 전달할 수 있게 합니다.

어떻게 동작하나요?

  • frps는 서버 프로그램으로, 일반적으로 공인 IP 주소가 있는 서버에서 실행됩니다.
  • frpc는 클라이언트 프로그램입니다. frps에 연결하며, 외부에서 접근할 수 있게 하려는 서비스에 접근할 수 있어야 합니다.

일반적인 리버스 프록시 구성에서는 요청이 frps에 도착한 뒤 연결을 통해 frpc로 전달되고, 설정한 서비스에 도착합니다.

어디에 사용할 수 있나요?

  • 로컬 네트워크의 웹 서비스에 접근할 수 있습니다. 예를 들어, 집에서 회사 컴퓨터에서 실행 중인 kimi code web 또는 deepseek harness에 접근할 수 있습니다.
  • SSH, VNC, RDP로 로컬 네트워크의 컴퓨터에 원격으로 연결할 수 있습니다. 예를 들어, 집에서 회사 컴퓨터의 터미널이나 원격 데스크톱을 사용할 수 있습니다.
  • FTP, SMB 등의 프로토콜로 NAS의 파일에 접근할 수 있습니다. 예를 들어, 출장 중에 집에 있는 NAS의 문서를 열거나 사진을 NAS에 백업할 수 있습니다.

frp 프로젝트는 TCP, UDP, HTTP, HTTPS 등의 프로토콜을 지원합니다. 구체적인 설정은 서비스 종류와 접근 방식에 따라 달라집니다.

FerryPorts는 어떤 역할을 하나요?

FerryPorts는 iOS용 frp 클라이언트입니다. 연결 설정을 관리하고 자신의 frps 서버에 연결하며 상태와 로그를 확인할 수 있습니다.

사용 권한이 있는 frps 서버와 해당 설정을 직접 준비해야 합니다. 백그라운드 동작은 iOS, 네트워크 상태, 권한 설정에 따라 달라집니다. 설정 방법과 앱에서 지원하는 기능은 FerryPorts 지원 가이드를 참고하세요.
