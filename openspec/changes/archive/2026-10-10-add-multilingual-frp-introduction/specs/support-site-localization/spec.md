## MODIFIED Requirements

### Requirement: 支持语言页面完整覆盖

支持网站 SHALL 在 `en/`、`zh/`、`zh-Hant/`、`ja/`、`ko/` 下分别提供 `index.html`、`support.html`、`privacy.html`、`frp.html`，各页 MUST 使用对应语言完整表达正文、标题、描述、导航、页脚及无障碍文本。品牌、作者署名、技术标识和命令 SHALL 保持原值。

#### Scenario: 直接访问日语或韩语页面
- **WHEN** 用户直接访问 `ja/` 或 `ko/` 下的任一主页、支持页、隐私政策或 frp 介绍页
- **THEN** 页面完整显示对应语言内容，不以英语正文或占位翻译替代
- **AND** 页面资源及站内锚点可用，主页操作、导航与页脚的站内目的地保持同语言

#### Scenario: 保留现有入口
- **WHEN** 用户访问根路径或现有中英文页面
- **THEN** 根页面继续进入 `en/index.html`，中英文 URL 和内容仍可访问
- **AND** 浏览器偏好语言不触发新的自动跳转

#### Scenario: 介绍页完整覆盖
- **WHEN** 用户直接访问任一语言目录的 `frp.html`
- **THEN** 获得该语言完整的 frp 介绍、站内导航及官方 GitHub 链接
- **AND** 同页语言选单可进入其余四种语言的 `frp.html`

### Requirement: 响应式与无障碍可用性

网站 MUST 保留共享静态样式、明暗主题、跳过导航入口、键盘焦点及隐私折叠内容的可访问性，选单入口与其图标 SHALL 保持垂直居中对齐。五语言导航和正文（包括新增 frp 介绍页）MUST 在窄屏及放大时保持可读可操作，MUST NOT 引入运行时翻译脚本、远程字体或追踪服务。

#### Scenario: 窄屏及放大
- **WHEN** 在 320 CSS 像素视口和桌面浏览器 200％ 缩放下分别浏览五语言的主页、支持页、隐私政策与 frp 介绍页
- **THEN** 导航可换行，文字、语言入口和展开选单无重叠或裁切，所有语言选项可访问，页面无影响阅读的横向溢出

#### Scenario: 键盘与主题
- **WHEN** 在明暗主题下通过键盘访问页面、语言选择及隐私折叠项
- **THEN** 焦点可见，跳过导航链接可达正文，语言链接可激活，折叠项可展开收起，相关无障碍名称使用当前页面语言

#### Scenario: 介绍页键盘访问
- **WHEN** 用户通过键盘浏览任一语言的 frp 介绍页
- **THEN** 可跳过导航进入正文、切换介绍页语言并激活首页、支持及 GitHub 入口
- **AND** 页面使用有序标题结构，明暗主题下焦点可辨识
