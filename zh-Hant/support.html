使用支援

開始使用

  1. 準備你有權使用的 frps 伺服器及相應驗證、代理設定。
  2. 在 FerryPorts 中新增設定，填寫伺服器資訊並儲存，然後啟用連線。
  3. 在設定詳細資訊中查看狀態與記錄；需要位置標註時，再根據系統提示授權定位。

連線失敗怎麼辦？

檢查伺服器位址、連接埠、驗證資訊及 frps 執行狀態，並確認目前網路可以存取該伺服器。短暫網路故障可能觸發有限次數的自動重試；修正設定後可使用「立即重試」。背景執行受到 iOS 排程、權限和網路狀態限制。

App 切換到背景後，連線中斷怎麼辦？

建議授予 FerryPorts 背景定位權限：打開 iOS「設定」→「隱私權與安全性」（舊版 iOS 為「隱私權」）→「定位服務」→「FerryPorts」，將存取權限設為「永遠」。如果暫時沒有「永遠」選項，請先在 App 內按提示允許定位，再回到設定查看。

背景定位用於為作用中的連線記錄標註大致位置，也可能幫助連線在背景維持更久。App 能否持續執行仍受 iOS 排程和網路狀態影響，請避免從多工畫面強制關閉 App。若連線已中斷，可回到 App 查看狀態與記錄，並使用「立即重試」。

如何匯入用戶端憑證與私鑰？

打開「更多 → 憑證與金鑰 → 匯入檔案」，選取多個 PEM 憑證、未加密私鑰與 CA 檔案；也可以從系統「檔案」App 分享或使用 FerryPorts 開啟。若系統沒有為 .key 提供入口，請將副檔名改為 .pem 或使用 App 內匯入。

每個檔案上限為 1 MiB，不支援 PKCS#12 或加密私鑰。可在可信任的電腦上使用 openssl pkey -in encrypted.key -out private.pem 移除私鑰密碼後再匯入。

點按憑證或金鑰，在「套用至…」中選擇 Profile，即可覆寫對應的 TLS 設定。一般憑證、私鑰、CA 分別設定 certFile、keyFile、trustedCaFile，合併檔案同時設定憑證和私鑰。向左滑動可重新命名或刪除；重新命名保留副檔名並同步 Profile 引用。以同名檔案替換後需重新啟動相關 Profile。

私鑰以明文 PEM 儲存在 App 容器內，受首次解鎖後的 iOS 檔案保護，且不納入 iCloud／Finder 備份；未使用應用程式層級加密，也未提供匯出功能。外部原始檔案由你管理。刪除憑證前，App 會提示受影響的 Profile。

回饋與隱私權問題

你可以透過 GitHub Issues 或傳送電子郵件至 eric_kwoc@icloud.com 回饋問題。請附 App 版本、iOS 版本、重現步驟和已移除敏感資料的錯誤資訊。

GitHub Issues 公開可見；電子郵件直接傳送給作者，不會公開顯示。不要傳送伺服器驗證資訊、完整 TOML、私鑰、個人位置或含敏感資訊的記錄。涉及隱私權的問題建議透過電子郵件聯絡作者。
