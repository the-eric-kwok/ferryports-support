認識 frp

什麼是 frp？

frp 是一個開源的反向代理工具，協助你透過可從公網存取的伺服器，存取 NAT 或防火牆後方的本機服務。

家庭或辦公室網路中的服務，可能無法從網際網路直接存取。frp 將這些服務連線至你管理的伺服器，由伺服器將請求轉送給它們。

它如何運作？

  • frps 是伺服器端，通常執行於具有公網 IP 位址的伺服器上。
  • frpc 是用戶端，它連線至 frps，並可存取你希望對外提供的服務。

在典型的反向代理情境中，請求先抵達 frps，再透過連線傳送至 frpc，最後抵達設定中指定的服務。

可以用來做什麼？

  • 存取區域網路中的網站或 Web 服務。例如，在家裡存取公司電腦上執行的 kimi code web 或 deepseek harness。
  • 透過 SSH、VNC、RDP 遠端連線至區域網路中的電腦。例如，在家裡使用公司電腦的終端機或遠端桌面。
  • 透過 FTP、SMB 等協定存取 NAS 上的檔案。例如，出差時讀取家中 NAS 的文件，或將照片備份到 NAS。

frp 專案支援 TCP、UDP、HTTP、HTTPS 等協定。具體設定取決於服務類型和存取方式。

FerryPorts 在其中扮演什麼角色？

FerryPorts 是 iOS 上的 frp 用戶端，可以管理連線設定、連線至自己的 frps 伺服器，以及查看執行狀態與日誌。

你需要自行準備有權存取的 frps 伺服器及設定。背景執行受 iOS、網路狀態和權限限制。設定方式和應用程式支援的功能，請參閱 FerryPorts 支援指南。
