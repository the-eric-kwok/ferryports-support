frp について

frp とは？

frp はオープンソースのリバースプロキシツールです。インターネットからアクセスできるサーバーを経由して、NAT やファイアウォールの内側にあるローカルサービスにアクセスできます。

家庭やオフィスのネットワークにあるサービスには、インターネットから直接アクセスできないことがあります。frp はそのサービスを自分で管理するサーバーに接続し、サーバーがリクエストを転送できるようにします。

どのように動作しますか？

  • frps はサーバー側のプログラムです。通常、パブリック IP アドレスを持つサーバーで動作します。
  • frpc はクライアント側のプログラムです。frps に接続し、公開したいサービスにアクセスします。

一般的なリバースプロキシ構成では、リクエストは frps に届き、接続を通じて frpc に転送され、設定したサービスに届きます。

どのような用途がありますか？

  • ローカルネットワーク内の Web サービスにアクセスする。例えば、自宅から会社のコンピュータで動作する kimi code web や deepseek harness にアクセスする。
  • SSH、VNC、RDP でローカルネットワーク内のコンピュータにリモート接続する。例えば、自宅から会社のコンピュータのターミナルやリモートデスクトップを利用する。
  • FTP、SMB などのプロトコルで NAS のファイルにアクセスする。例えば、出張先から自宅の NAS にある書類を開いたり、写真を NAS にバックアップしたりする。

frp プロジェクトは TCP、UDP、HTTP、HTTPS などのプロトコルに対応しています。設定はサービスの種類とアクセス方法によって異なります。

FerryPorts の役割は？

FerryPorts は iOS 向けの frp クライアントです。接続設定を管理し、自分の frps サーバーに接続して、状態やログを確認できます。

利用権限のある frps サーバーとその設定を自分で用意する必要があります。バックグラウンドでの動作は、iOS、ネットワークの状態、許可設定に左右されます。設定方法やアプリが対応する機能については、FerryPorts のサポートガイドをご覧ください。
