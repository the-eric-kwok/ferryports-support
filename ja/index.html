iOS 向け frp クライアント

あなたのサービスを、つなぐ。

FerryPorts は iOS 向けの frp クライアントです。自分のサーバーを設定し、接続状態やログを確認できます。必要に応じて、接続記録におおよその位置情報を付けることもできます。

自宅から会社のコンピュータで動作する kimi code や deepseek harness などの Web サービスにアクセスしたり、コンピュータのターミナルやデスクトップをリモートで使ったり、外出先から NAS のファイルを開いてバックアップしたりできます。利用権限のある frps サーバーとその設定が必要です。
