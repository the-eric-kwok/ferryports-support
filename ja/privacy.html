プライバシーポリシー

プライバシーポリシー

更新日：2026年9月20日。

FerryPorts は 郭耀铭（Guo Yaoming）が開発し、ユーザーが選択した frps サーバーに接続するアプリです。本ポリシーは、アプリとこのサポートサイトに適用されます。

  • 広告や利用状況の追跡はありません

    FerryPorts のアカウントは不要です。アプリには広告、広告トラッキング、利用状況の分析サービスはありません。

  • 設定と履歴はデバイス内に保存されます

    サーバー設定と接続履歴はローカルで暗号化されます。アプリが診断ログ、位置情報、接続履歴を開発者へ自動送信することはありません。ただし、接続プロトコルや有効にした機能によって、以下に説明する設定やその他のデータが送信される場合があります。

  • 位置情報の利用は任意です

    許可を得た場合、アプリはアクティブな接続におおよその位置情報を付けます。各接続には最新の位置だけを保存し、移動経路は記録しません。iOS の「設定」で位置情報へのアクセスを無効にできます。

  • 接続にはネットワークアクセスが必要です

    選択したサーバーは、接続の確立、認証、プロキシ通信に必要なデータを受信します。Apple マップと本サイトのホスティング提供元である GitHub も、サービスの提供に必要なリクエスト情報を処理します。

  • ローカルデータを削除できます

    接続記録やプロファイルを削除できます。設定と鍵を削除するには、アプリ内でプロファイルを削除してください。アンインストールだけではキーチェーン項目が残る場合があります。ローカルで削除してもサーバーのログは削除されません。

データの取り扱い

各見出しを開くと、保存方法、第三者サービス、削除の制限について確認できます。

デバイス内のデータ

サーバー設定、認証情報、プロキシ設定は、AES-GCM で暗号化した文書に保存されます。文書の鍵は、デバイスに紐付いたシステムのキーチェーン項目に保存されます。プロファイル名、有効状態、文書識別子はアプリのローカル設定に保存されます。アプリが認証パスワードをプロファイル名に挿入することはありません。暗号化された設定ファイルと接続履歴ファイルは、システムのバックアップ対象から除外されます。

現在のセッションの診断ログは、アプリ内で表示するため、容量を制限したメモリバッファに保持されます。サーバーのアドレス、プロキシ名、タイムスタンプ、エラーが含まれる場合があります。アプリがこれらのログを開発者へ自動送信することはありません。ログの内容をコピーまたは共有した場合、提供した内容は共有相手に渡ります。

位置情報と接続履歴

許可を得た場合、接続の開始中または実行中に、おおよその位置情報を接続記録に付けます。各セッションは最新の位置だけを保持し、移動経路、高度、速度、進行方向は保存しません。各プロファイルには、開始時刻、最終アクティビティ時刻、結果を含む直近最大 50 件の記録を保持します。

これらの記録はローカルで暗号化されます。アプリ自体が位置情報や接続履歴を開発者または frps サーバーへ送信することはありません。地図には Apple MapKit を使用します。Apple の地図サービスに必要なリクエストと処理には、Apple のプライバシーポリシーが適用されます。地図が完全にオフラインで動作することは保証しません。

iOS の「設定」で位置情報へのアクセスを変更または取り消せます。バックグラウンドの位置情報はアクティブな接続記録に位置を付けるために使用され、接続をバックグラウンドでより長く維持できる場合もあります。許可設定の変更、アプリの強制終了、システムによる終了で、この動作が中断されることがあります。

ユーザーが選択したサーバー

プロファイルを有効にすると、接続の確立、認証、プロキシのネゴシエーションに必要なデータが、選択した frps サーバーへ送信されます。frp のログインプロトコルには、OS が返すホスト名、OS の種類、プロセッサのアーキテクチャ、frp のバージョン、ログインのタイムスタンプ、セッション識別子、設定されたユーザー名、クライアント識別子、メタデータが含まれます。iOS が返すホスト名は汎用的な名前の場合があります。これらは接続プロトコルの項目であり、FerryPorts の広告識別子ではありません。サーバーは、設定されたサービスの提供に必要な認証プロトコルのデータやプロキシ設定も受信します。

サーバーと通信先のエンドポイントは、IP アドレス、接続時刻、設定されたプロキシ通信を受信できます。有効にした機能に応じて、DNS プロバイダはドメインの問い合わせを受信し、OIDC 認証プロバイダは設定されたクライアント認証情報とトークン要求のパラメータを受信します。また、XTCP の NAT トラバーサルでは、ネットワークアドレスを調べるために STUN サービスへ接続します。別の STUN サーバーを設定していない場合、frp は既定で stun.easyvoip.com:3478 を使用します。通常のプロキシ接続には、この XTCP の探索処理は必要ありません。プロキシ、認証、その他のエンドポイントも設定で選択できます。

インポートした証明書と秘密鍵はアプリのコンテナ内に平文の PEM として保存され、初回ロック解除後に利用できる iOS のデータ保護で保護されます。iCloud と Finder のバックアップ対象からは除外されます。プロファイル文書に適用されるアプリ独自の暗号化は使用しません。これらのファイルは「その他」→「証明書と鍵」で削除してください。プロファイルを削除しても、他のプロファイルと共有されている可能性のある証明書は自動削除されません。外部にある元のファイルやコピーはご自身で管理してください。

設定された証明書ファイル、token ファイル、静的ファイル配信用ディレクトリは、アプリのコンテナ内に限定されます。この境界を越えるパスやシンボリックリンクは拒否されます。カスタム DNS の問い合わせは、選択した DNS サービスが処理します。

static_file プラグインを有効にすると、そのサービスへのリクエストにより、設定したディレクトリ内の読み取り可能なファイル、ディレクトリ一覧、サイズや更新日時などのファイルメタデータを取得できます。HTTP レスポンスに Last-Modified ヘッダーが含まれる場合があります。これはユーザーが設定するファイル配信であり、診断情報の分析ではありません。frp の管理用 Web サーバーを有効にした場合、到達可能なクライアントは、選択した認証設定とネットワーク設定に従って接続状態や設定情報を取得できる場合があります。

データの受信者、暗号化、ログの保存期間、処理は、サーバー、サービス、設定によって異なります。信頼でき、利用権限のあるサーバーだけに接続し、運営者のプライバシーポリシーを確認してください。ローカルに保存することは、ネットワーク送信がないことを意味しません。ネットワーク通信はアプリの主要な機能です。

データを削除した後に残るものは？

個別の接続記録を削除したり、履歴を消去したりできます。プロファイルを削除すると、その暗号化された設定文書、接続履歴、文書の鍵が削除されます。通常、アンインストールするとアプリのローカルデータコンテナは削除されますが、iOS のキーチェーン項目は残る場合があります。鍵を削除したい場合は、先にアプリ内でプロファイルを削除してください。ローカルで削除しても、サーバーログ、別の場所に保存したコピー、他のプラットフォームへの投稿は削除されません。

このサイトの閲覧やお問い合わせでは、どの情報を使用しますか？

このサイトは GitHub Pages でホストされ、追加の分析スクリプト、広告、追跡 Cookie はありません。GitHub は、GitHub プライバシーステートメントに基づき、ホスティングの提供と保護のために IP アドレスや技術的なリクエスト情報を処理する場合があります。GitHub を通じてお問い合わせいただく場合、GitHub とメンテナーが提供された内容を処理します。公開 Issue は誰でも閲覧できます。eric_kwoc@icloud.com へメールでお問い合わせいただくこともできます。作者がフィードバックを受け取り、公開せずに対応します。関連するメールサービス提供者は、メールの配信と保存を処理します。認証情報、設定全体、個人の位置情報が写ったスクリーンショットを投稿しないでください。
