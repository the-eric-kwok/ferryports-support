使用支持

开始使用

  1. 准备你有权使用的 frps 服务器及相应认证、代理配置。
  2. 在 FerryPorts 中新增配置，填写服务器信息并保存，然后启用连接。
  3. 在配置详情中查看状态与日志；需要位置标注时，再根据系统提示授权定位。

连接失败怎么办？

检查服务器地址、端口、凭据及 frps 运行状态，并确认当前网络可以访问该服务器。短暂网络故障可能触发有限自动重试；修正配置后可使用“立即重试”。后台运行受到 iOS 调度、权限和网络状态限制。

反馈与隐私问题

使用 GitHub Issues提供支持。请附 App 版本、iOS 版本、复现步骤和经过脱敏的错误信息。

公开 Issue 对任何人可见。不要发送服务器凭据、完整 TOML、私钥、个人位置或含敏感信息的日志。隐私问题请先仅描述问题类别，请勿公开个人资料。

数据存储与删除方式见隐私政策。

Support

Prepare an authorized frps server and configuration, create a profile in FerryPorts, save it, and enable the connection. Review status and logs in profile details. Grant location access only if you want location labels for connection records.

If a connection fails, check the server address, port, credentials, server availability, and network access. Temporary failures may trigger limited retries. Use Retry Now after correcting a configuration. Background connectivity depends on iOS, permissions, and network conditions.

Our support channel is GitHub Issues. Include your app and iOS versions, reproduction steps, and sanitized errors. Issues are public: never post credentials, full configurations, private keys, personal locations, or sensitive logs. For privacy questions, describe the category of concern without posting personal details. See our Privacy Policy for storage and deletion information.
