认识 frp

什么是 frp？

frp 是一个开源的反向代理工具，帮助你通过公网可访问的服务器，访问 NAT 或防火墙后面的本地服务。

家庭或办公室网络中的服务，可能无法从互联网直接访问。frp 将这些服务连接到你管理的服务器，由服务器把请求转发给它们。

它如何工作？

  • frps 是服务端，通常运行在具有公网 IP 地址的服务器上。
  • frpc 是客户端，它连接到 frps，并能访问你希望对外提供的服务。

在典型的反向代理场景中，请求先到达 frps，再通过连接传递给 frpc，最终到达配置中指定的服务。

可以用来做什么？

  • 访问局域网中的网站或 Web 服务。例如，在家里访问公司电脑上运行的 kimi code web 或 deepseek harness。
  • 通过 SSH、VNC、RDP 远程连接局域网中的电脑。例如，在家里使用公司电脑的终端或远程桌面。
  • 通过 FTP、SMB 等协议访问 NAS 上的文件。例如，出差时读取家中 NAS 的文档，或把照片备份到 NAS。

frp 项目支持 TCP、UDP、HTTP、HTTPS 等协议。具体配置取决于服务类型和访问方式。

FerryPorts 在其中做什么？

FerryPorts 是 iOS 上的 frp 客户端，可以管理连接配置、连接自己的 frps 服务器，以及查看运行状态和日志。

你需要自行准备有权访问的 frps 服务器及配置。后台运行受 iOS、网络状态和权限限制。设置方法和应用支持的功能，请参阅 FerryPorts 支持指南。
