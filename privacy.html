隐私政策

更新日期：2026 年 9 月 18 日 · English

本政策说明 FerryPorts App 及本支持网站的数据处理方式。FerryPorts 由郭耀铭开发，是连接用户自行选择的 frps 服务器的客户端。App 不要求注册 FerryPorts 账号，没有内置广告、广告追踪或使用行为分析服务。

保存在设备上的数据

服务器地址、认证信息及代理配置保存在本机加密配置文档中，采用 AES-GCM 加密，文档密钥存放在设备绑定的系统 Keychain 中。配置名称、启用状态及文档标识等索引保存在 App 的本机偏好设置中；App 不会将认证密码写入配置名称。加密配置与连接记录文件设置为排除系统备份。

运行日志用于在 App 内排查连接问题，当前启动会话的日志保存在有限大小的内存缓冲区中。日志可能包含服务器地址、代理名称、时间和错误信息。App 不会将这些日志外传。

位置与连接记录

在你授权且存在启动中或运行中的连接时，App 使用位置为连接记录标注大致地点。每条会话只保留最近一次位置，不保存移动轨迹、海拔、速度或方向；每个配置最多保留最近 50 条连接记录。

连接记录还包括开始时间、最近活动时间及连接结果，使用本机加密存储。App 自身不把这些位置或连接历史上传给开发者或 frps 服务器。地图使用 Apple MapKit，地图服务所需请求及相关处理受 Apple 隐私政策约束；本政策不承诺 Apple 地图服务完全离线。

你可以在 iOS 设置中关闭或调整定位权限。后台定位仅用于活跃连接的记录标注，也可能延长连接在后台的运行时间；撤销权限、强制退出或系统终止可能中断该行为。

连接到你选择的服务器

启用配置会向你指定的 frps 服务器发送建立连接、认证和代理协商所需的数据。服务器及实际通信端点可接收到网络地址、连接时间、认证协议数据，以及由配置决定的代理业务流量。具体接收方、加密保护、日志保留与用途取决于你选择的服务器、通信服务及配置。请仅连接可信且获授权的服务器，并向服务器运营者了解其隐私政策。

“本机存储”不意味着 App 完全不传输数据。FerryPorts 的核心功能需要网络通信；本政策不代表第三方服务器运营者作出承诺。

删除与保留

你可以删除单条连接记录或清空记录。删除配置会清理关联的加密配置文档、连接记录及文档密钥。卸载 App 通常会移除其本机数据容器，但 iOS Keychain 项目可能保留，因此不应把卸载理解为清除所有密钥的保证；如需清理配置，请先在 App 内删除。App 的本机删除操作不会删除服务器端日志、你自行保存的副本或发布到其他平台的内容。

本网站与主动联系

本网站使用 GitHub Pages 托管，无自行添加的分析脚本、广告或追踪 Cookie。访问网站时，GitHub 可能处理 IP 地址及技术请求信息，以提供和保护托管服务，适用 GitHub 隐私声明。若你主动通过 GitHub 提交问题，GitHub 与维护者会处理你提供的内容；公开 Issue 对所有人可见。请勿提交凭据、完整配置或包含个人位置的截图。

Privacy Policy

Updated September 18, 2026. FerryPorts is an iOS frp client developed by 郭耀铭 (Guo Yaoming). It connects to servers you choose. No FerryPorts account is required, and the app includes no advertising, advertising tracking, or usage analytics service.

On-device data

Server settings, authentication information, and proxy configuration are stored in AES-GCM encrypted documents. Document keys are stored in device-bound system Keychain items. Profile names, enabled states, and document identifiers are stored in local app preferences; the app does not insert authentication passwords into profile names. Encrypted configuration and connection-history files are excluded from system backups.

Current-session diagnostic logs are kept in a bounded memory buffer for display in the app. They may contain server addresses, proxy names, timestamps, and errors. The app does not transmit these logs outside the device.

Location and connection history

With your permission, while a connection is starting or running, the app uses approximate location to label connection records. Each session keeps only its latest location, not a movement trail, altitude, speed, or heading. Each profile retains up to 50 recent records, including start time, latest activity time, and outcome.

These records are encrypted locally. The app itself does not upload location or connection history to the developer or frps server. Maps use Apple MapKit. Requests and processing required by Apple's map service are governed by Apple's Privacy Policy; maps are not promised to work entirely offline.

You can change or revoke location access in iOS Settings. Background location labels active connection records and may also allow a connection to run longer in the background. Permission changes, force quitting, or system termination may interrupt this behavior.

Your selected servers

Enabling a profile sends data required for connection setup, authentication, and proxy negotiation to your selected frps server. The server and communication endpoints can receive network addresses, connection times, authentication-protocol data, and configured proxy traffic. Recipients, encryption, log retention, and processing depend on your server, services, and configuration. Only connect to trusted, authorized servers and consult their operators' privacy policies. Local storage does not mean no network transmission; network communication is central to the app's functionality.

Retention and deletion

You can delete individual connection records or clear history. Deleting a profile removes its encrypted configuration document, connection history, and document key. Uninstalling normally removes the app's local data container, but iOS Keychain items may remain. Delete profiles inside the app first when you want to remove their keys. Local deletion does not erase server logs, copies you saved elsewhere, or content you posted to another platform.

Do not post credentials, full configurations, or screenshots containing personal locations.

See the support page for privacy questions. Policy changes will be reflected on this page with an updated date; material changes will also be communicated where appropriate.
